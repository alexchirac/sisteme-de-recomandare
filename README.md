## Proprietatile din `books.csv`

Fisierul contine urmatoarele coloane:

| Proprietate | Tip | Descriere |
|---|---|---|
| `title` | string | Titlul cartii. |
| `subtitle` | string | Subtitlul cartii, daca exista. |
| `authors` | string | Autorul sau autorii cartii. |
| `categories` | string | Categoria sau categoriile cartii. |
| `thumbnail` | string | URL-ul imaginii de coperta. |
| `description` | string | Descrierea cartii. |
| `published_year` | int | Anul publicarii. |
| `average_rating` | double | Nota medie a cartii. |
| `num_pages` | int | Numarul de pagini. |
| `ratings_count` | int | Numarul de evaluari primite. |

https://www.kaggle.com/datasets/dylanjcastillo/7k-books-with-metadata
